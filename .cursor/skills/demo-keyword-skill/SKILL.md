# 示例关键词 Skill

## 何时使用
- 用户提到：`demo-skill`、`skill-example`、`关键字触发`
- 用户希望：快速得到 Unity 客户端改动建议 + 执行清单

## 执行步骤
1. 先用 2-4 条要点复述需求与边界。
2. 给出最小可行实现（MVP）方案，优先少改动。
3. 输出一份可执行检查清单。

## 输出格式
- 目标
- 最小实现
- 检查清单
- 风险与下一步
